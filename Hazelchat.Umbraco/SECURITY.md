# Security

Please report a security problem in this package or in Hazelchat to hello@hazelchat.co, with "Security" in the subject. We answer within one business day and fix confirmed problems in a new release.

The package prints one script tag with your public widget key, which is not a password. The script address is fixed in the code and cannot be changed in the settings. The package makes no requests from your site, stores nothing, and only changes finished HTML pages that Umbraco rendered from published content.
